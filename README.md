# Чудо Обувл - каталог (chudo-obuv-app)
Учебный проект - десктопное приложение. каталог обувного магазина с бд и ролевой системой 

**Что используется**

БД в SQL Server, язык С#, интерфейс WPF (xaml)

**Функционал** 
1) Роли: Гость (просмотр), Авторизованный пользователь (заказ), Менеджер (просмотр заказов), Администратор (удаление заказов, изменение даты).
2) Каталог: Поиск, фильтрация по категориям, сортировка по цене.
3) Cкидки: Автоматический расчет скидки 25% на товары, по которым не было заказов за прошлый месяц.
4) Учет на складе: Визуальное выделение красным цветом товаров, которых осталось менее 3 штук. При оформлении заказа количество товара на складе уменьшается, при удалении заказа администратором возвращается обратно.
